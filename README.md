# 🌱 RERO - Renewable Energy Resource Optimizer

RERO is a full-stack web application that leverages machine learning to help users optimize the use of renewable energy resources. It consists of three main components: a modern frontend interface, a robust backend API, and a Flask-based ML model, all deployed and working together seamlessly.

## 🧠 Features

- ✅ User authentication (login/signup)
- 📈 Dynamic dashboard with visual charts (Recharts)
- 🔍 Prediction of optimal renewable energy source using ML
- 📤 RESTful APIs built with Node.js and Express
- 🧪 Flask-based ML model integration with backend
- 💡 Real-time, interactive, and responsive frontend with Next.js (App Router)
- 📊 Visualization of solar, wind, and hydro energy data
- 🌍 Deployed on Vercel and Render for full-stack cloud experience
